# Telegram SmartQuizBot

Простой телеграм-бот для прохождения квиза на Python.
Ссылка на бота: https://t.me/Smartly_Quizz_Bot
---

## Команды бота

### `/start`
Приветствует пользователя и показывает кнопку **"Начать игру"**.

---

### `/quiz`
Запускает квиз с начала (сбрасывает прогресс).

---

### **Кнопка "Начать игру"**
Тоже запускает квиз (аналогично `/quiz`).

---

### `/stats`
Показывает статистику игроков (только по последнему результату).

---

## Как работает квиз

- Бот задаёт вопросы по очереди.
- Пользователь выбирает ответ кнопкой.
- После ответа кнопки удаляются, а бот пишет:
  - **Ваш ответ: ...**
  - **Верно/Неверно**
- В конце выводится результат:  
  **🏁 Квиз завершён! Ваш результат: X из 10**

---

## Сохранение результатов

Результаты сохраняются в SQLite базе `quiz_bot.db`.

Сохраняется только **последний результат** каждого пользователя.

---
